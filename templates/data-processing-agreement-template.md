# Data Processing Agreement (DPA) Template

Use this as a starting structure for agreements with any vendor or third party that processes personal data on your behalf (payment processors, cloud hosts, marketing tools, logistics partners, etc.). This is a structural template, not a substitute for legal review, especially for high-volume or high-risk data relationships.

---

## Data Processing Agreement

**Between:** [Your business name] ("Controller")
**And:** [Vendor/processor name] ("Processor")

### 1. Subject matter and duration

[Describe what service the processor provides and for how long this agreement applies.]

### 2. Nature and purpose of processing

[Specifically what personal data the processor will handle, and for what purpose. Be precise, "customer names and delivery addresses for order fulfillment," not "customer data."]

### 3. Categories of data subjects

[Whose data is being processed: customers, employees, applicants, etc.]

### 4. Categories of personal data

[List specifically: names, emails, phone numbers, payment details, etc.]

### 5. Processor obligations

The Processor agrees to:
- Process personal data only on documented instructions from the Controller
- Ensure staff handling the data are bound by confidentiality obligations
- Implement appropriate technical and organizational security measures
- Not engage a sub-processor without the Controller's prior written authorization
- Assist the Controller in responding to data subject rights requests
- Notify the Controller without undue delay upon becoming aware of a personal data breach
- Delete or return all personal data at the end of the service, unless retention is legally required
- Make available information necessary to demonstrate compliance with this agreement

### 6. Sub-processors

[List any approved sub-processors, or state that none are currently authorized. Any new sub-processor requires notice and approval per section 5.]

### 7. Security measures

[Describe the specific security measures the processor commits to, encryption standards, access controls, etc.]

### 8. Breach notification timeline

[Specify the timeframe the Processor must notify the Controller within, this should be fast enough for the Controller to still meet the 72-hour NDPC notification window.]

### 9. International data transfers

[If applicable, state where data is stored/processed and what safeguards apply to any cross-border transfer.]

### 10. Termination and data return

[What happens to the data when this agreement ends: deletion timeline, confirmation of deletion, or return of data.]

### 11. Liability

[Standard liability and indemnification clauses, recommend legal review for this section specifically.]
